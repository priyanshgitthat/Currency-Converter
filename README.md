# Currency Converter

A simple and intuitive web application that allows users to convert one currency to another in real-time.

## Features

- **Real-Time Currency Conversion**: Convert currencies using live exchange rate data fetched from an API.
- **Multiple Currencies Supported**: Supports a wide range of global currencies for conversion.
- **User-Friendly Interface**: Easy-to-use design for seamless conversion experience.

## How to Use

1. Open `index.html` in your browser.
2. Select the currencies you want to convert from and to.
3. Enter the amount to convert and click "Convert".
4. The result will be displayed with the converted amount.

## Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **API Integration**: Currency exchange rate API
